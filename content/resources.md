# 감리 도구 및 리소스

정보시스템 감리 업무에 활용되는 도구와 리소스를 카테고리별로 정리했습니다.

## 1. 정보시스템 감리 도구

최근 클라우드 네이티브 환경 확산, AI 기반 자동화, 그리고 제로 트러스트 보안 모델의 도입에 따라 정보시스템 감리 현장에서도 새로운 도구들이 필수적으로 활용되고 있습니다.

### 1.1 감리 도구 체계

| 분류 | 주요 도구 (Classic) | 최신 트렌드 도구 (Modern) |
|------|-------------------|------------------------|
| 정적분석 | SonarQube, Fortify | Snyk, CodeQL, AI Code Review |
| 보안점검 | Nessus, Burp Suite | Wiz, Prisma Cloud, Trivy |
| 네트워크 | Wireshark, Nmap | Datadog, Faddom (가시성 확보) |
| DB 분석 | TOAD, DBeaver | Cyera (DSPM), Unity Catalog |
| 성능/장애 | JMeter, LoadRunner | k6, Locust, Gremlin |
| 감리 관리 | Excel, 한글 | AuditBoard, Hyperproof (GRC 자동화) |

### 1.2 정적 분석 (Static Analysis & AI Review)

기존의 규칙 기반 분석을 넘어, AI 가 코드의 맥락을 이해하고 수정 제안까지 제공하는 도구들이 부상하고 있습니다.

- **기존 도구**: SonarQube, Checkmarx, Fortify SCA
- **최신 도구**:
  - **Snyk**: 오픈소스 라이브러리 취약점 (SCA) 과 컨테이너 보안을 동시에 점검
  - **CodeQL**: GitHub 기반의 세밀한 쿼리 분석으로 복잡한 보안 취약점 탐색
  - **CodeRabbit / Qodo (Codium)**: AI 에이전트가 코드 리뷰 수행

### 1.3 보안 및 클라우드 진단 (Security & CSPM)

단순 웹 취약점 점검을 넘어, 클라우드 설정 오류 (Misconfiguration) 및 공급망 보안 점검이 중요해졌습니다.

- **기존 도구**: Nessus, OWASP ZAP, Burp Suite
- **최신 도구**:
  - **Wiz / Prisma Cloud**: 클라우드 설정 오류 점검 CSPM 도구
  - **Trivy**: 컨테이너 이미지와 IaC 설정 취약점 검사
  - **Nuclei**: 최신 취약점 템플릿을 활용한 자동 스캔

### 1.4 네트워크 및 관제 분석 (Network & Observability)

패킷 분석 중심에서 애플리케이션 간의 상호작용과 전체 흐름을 시각화하는 도구로 진화했습니다.

- **기존 도구**: Wireshark, Nmap, Tcpdump
- **최신 도구**:
  - **Datadog / New Relic**: 인프라 전반의 모니터링 및 로그 분석
  - **Faddom / Dynatrace**: 하이브리드 클라우드 환경에서 서버 간 연결 관계 맵핑

### 1.5 데이터베이스 및 데이터 거버넌스 (DB & Data Governance)

단순 SQL 작성을 넘어 개인정보 보호 준수 여부와 데이터 오남용을 감시하는 기능이 중요합니다.

- **기존 도구**: TOAD, SQL Developer, DBeaver
- **최신 도구**:
  - **Cyera**: 데이터 보안 태세 관리 (DSPM) 도구
  - **Databricks Unity Catalog**: 클라우드 데이터 레이크 환경에서 데이터 권한 및 계보 추적

### 1.6 성능 및 부하 테스트 (Performance & SRE)

전통적인 부하 테스트에서 서비스 지속성을 확인하는 카오스 엔지니어링으로 영역이 넓어지고 있습니다.

- **기존 도구**: JMeter, LoadRunner
- **최신 도구**:
  - **k6**: Go 언어 기반의 현대적인 부하 테스트 도구
  - **Locust**: Python 기반 대규모 동시 접속 시뮬레이션
  - **Gremlin**: 시스템에 의도적으로 장애를 주입하는 카오스 엔지니어링 도구

### 1.7 JMeter 성능테스트 가이드

JMeter 는 Apache 에서 개발한 오픈소스 부하 테스트 도구로, 웹 애플리케이션의 성능과 부하를 측정하는 데 널리 활용됩니다.

🔗 **[JMeter 온보딩 가이드 바로가기](https://jeonck.github.io/jmeter-onboard/)**

- JMeter 설치 및 설정 방법
- 테스트 플랜 작성 및 스레드 그룹 구성
- 다양한 리스너와 어설션 활용
- 분산 테스트 및 결과 분석

## 3. 법령 및 표준

### 3.1 법령 및 행정규칙 (최우선 준수)

- **전자정부법 / 동법 시행령**: 감리 수행의 법적 근거 및 대상 사업 규정
- **정보시스템 감리기준 (행정안전부 고시)**: 감리 절차, 인력 배치, 대가 산정, 검사항목 등 실무 표준
- **소프트웨어 진흥법**: SW 품질보증 및 과업 변경, 적정 대가 산정 관련 준수

### 3.2 보안 및 취약점 가이드라인 (통제 분야)

- **SW 개발 보안 가이드 (행정안전부)**: 이른바 '시큐어 코딩' 가이드. 공공사업 감리 시 필수 점검 항목
- **KISA 보안 가이드라인**: 클라우드 서비스 보안인증 (CSAP) 가이드, 개인정보 보호 기술적·관리적 보호조치 기준
- **OWASP Top 10**: 웹 애플리케이션의 10 대 보안 취약점 (국제 표준 가이드)
- **ISO/IEC 29147**: 보안 취약점 공개 절차에 관한 국제 표준
- **주요 정보통신기반시설 취약점 분석·평가 가이드 (국정원/KISA)**: 서버, 네트워크, DB 등 인프라 보안 점검의 기준

### 3.3 품질 및 산출물 표준 (기술 분야)

- **ISO/IEC 25010 (구 ISO/IEC 9126)**: 소프트웨어 품질 모델
- **ISO/IEC 12207**: 소프트웨어 생명주기 프로세스 표준
- **공공기관 웹 사이트 구축·운영 가이드 (행정안전부)**: 웹 표준 준수, 접근성 (WA), 호환성 점검 기준

### 3.4 인프라 및 기타 (참고 분야)

- **정보통신공사 감리기준 (과학기술정보통신부)**: 정보시스템 구축 중 물리적 네트워크 선로, 구내 통신 설비 등이 포함된 경우에 한해 부분적으로 적용
